# CPFS - CyClone Power File Share

| | |
|---|---|
| نسخه | 0.3.0 (در حال توسعه) |
| پلتفرم | Windows 10 و 11 (خانگی یا حرفه‌ای) |
| نیازها | .NET Framework 4.8 (در Windows 10 نسخهٔ 1903 به بعد و در Windows 11 به‌صورت پیش‌فرض وجود دارد)، دسترسی مدیر |
| صفحهٔ اصلی | https://cyclone9.ir/cpfs.html |
| مجوز | MIT (فقط کد؛ بخش [مجوز](#مجوز) را ببینید) |

بازنویسی CPFS به‌شکل برنامه‌ای برای Windows در جریان است. هنوز نسخه‌ای منتشر نشده و چیزی برای دانلود نیست؛ هرچه در ادامه آمده توضیح کاری است که قرار است برنامه انجام دهد.

## کاری که CPFS انجام می‌دهد

با CPFS یک پوشه روی رایانهٔ Windows به اشتراک گذاشته می‌شود تا تلفن‌ها و دستگاه‌های دیگر با نام `ComputerName.local` به آن برسند. دستگاه‌ها با یک حساب SMB جداگانه که برای همین کار ساخته می‌شود وارد می‌شوند، نه با حساب Windows شما، و اشتراک با تنظیمات امنیتی تقویت‌شدهٔ Windows راه‌اندازی می‌شود.

## برنامه چه امکاناتی خواهد داشت

- صفحه‌هایی برای راه‌اندازی، پایش، همگام‌سازی، اتصال و حذف نصب.
- ظاهری هم‌سبک Windows 11 با زمینهٔ سیستم، روشن و تیره.
- نخست انگلیسی، سپس فارسی، عربی و ترکی.
- انتخاب دلخواه حرف درایو، نام درایو و نام میان‌بر.
- راهنمای اتصال با کد QR برای Windows، macOS، Linux، Android و iOS، از راه نام `.local`، نشانی IP شبکهٔ Wi-Fi یا LAN، یا نشانی VPN.
- همگام‌سازی اختیاری یک زیرپوشهٔ اشتراک با سرور Linux، از راه کانالی رمزگذاری‌شده.
- حذف نصب، که تنظیمات اصلی Windows را بازمی‌گرداند.
- حذف نشدن فایل‌هایتان. CPFS هرگز خودش چیزی را در پوشهٔ اشتراکی حذف، جابه‌جا یا رونویسی نمی‌کند. وقتی همگام‌سازی روشن است، فایلی که در یک طرف حذف یا جایگزین شود، در طرف دیگر در پوشهٔ نسخه‌ها نگه داشته می‌شود و پاک نمی‌شود.
- شناسایی نصب‌های موجود که با اسکریپت‌های قدیمی‌تر CPFS انجام شده‌اند.
